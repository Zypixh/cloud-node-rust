# cloud-node-rust 1.2.0

## 概述

1.2.0 修复 AnyTLS/SNI 跨地域上传在节点压力下被 relay 提前截断的问题，并修复 metrics 首次初始化可能造成的 DashMap 重入死锁。

## TCP/SNI relay

- established TCP/SNI relay 默认不再使用按方向的压力 idle timeout，避免 backend 暂时没有响应数据时取消正在进行的上传。
- async-copy 和 Linux zero-copy relay 使用一致的 timeout 选项语义；连接 admission、握手超时和 L4 防御仍然保留。
- 保留 TCP 自身的重传与乱序恢复能力，不把线路丢包误判为应用层断流。

## Metrics

- 在进入 `DashMap::entry()` 前计算 server 数量预算。
- `ServerMetrics` 构造过程不再重入 `METRICS.servers`，避免首次创建 server metrics 时卡死 relay。
