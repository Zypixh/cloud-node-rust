# cloud-node-rust 1.0.8

本文件记录 `1.0.8` 的发布说明。

## 概述

1.0.8 重点修复 SNI passthrough、TCP 和 UDP 四层代理的统计与访问日志细节，并新增单节点本地计费流量口径配置。默认继续保持 FlexCDN/GoEdge 的单下行计费口径；需要时可在本地配置中启用上下行合计计费。

## 统计和计费

- 修正 SNI passthrough 和 TCP 双向转发在异常断开时丢失已转发字节的问题，失败前的上下行流量现在会继续进入统计链路。
- 修正 UDP 代理统计：按包记录上下行增量，失败和会话结束路径都会正确调用请求结束逻辑，避免 active connection 泄漏。
- 确认 SNI、普通 L7、TCP 和 UDP 均复用控制面的 Server 级统计接口上报，不新增不兼容接口。
- 服务级带宽上报对齐 EdgeNode 的 `bandwidthAlgo`：用户配置为 `avg` 时按 5 分钟总流量平均带宽上报，其他情况继续按 2 秒采样峰值带宽上报。
- 新增 `billing.countInboundTraffic` 本地配置项，默认 `false` 时只把节点下行流量计入控制面带宽和日统计计费字段；设置为 `true` 后当前节点按上下行合计计费。

## SNI 访问日志

- 修正 SNI passthrough 访问日志中 `request_uri` 使用完整 URL 导致控制面展示重复 URL 的问题。
- SNI 日志现在使用 `CONNECT host TCP` 请求行，并保持 `scheme=https`、`host` 和 `/` 路径分离。
- 补齐 SNI 访问日志的 `time_iso8601` 和 `time_local` 字段，避免控制面展示缺少时间。
- 修正访问日志 `timestamp` / `msec` 数值时间被本地时区偏移污染的问题，避免日志被写入未来时间导致控制面查询不到。

## 配置和文档

- `configs/api_node.yaml` 示例新增 `billing.countInboundTraffic`。
- 配置文档说明默认下行计费和可选上下行合计计费的差异。
- 安装脚本升级时默认获取最新 Release 并原子覆盖二进制，安装/升级完成后交互询问是否重启或启动服务。
- README 和运维文档更新到 1.0.8 发布入口。

## GitHub Actions 构建缓存

- Release workflow 现在会在 `main` 分支 push 时预热 release 构建缓存，并在 tag 发布时复用同一组缓存。
- main 分支预热改为只在 Cargo、proto、tests、vendor、TOA、Pingora 等构建输入变化时触发，普通 `src/` 代码和 workflow 文件调整不再触发预热。
- Rust release 构建缓存显式纳入 target、CPU variant 和编译 flags，避免不同 CPU 产物互相污染。
- 移除旧系统兼容包的自动构建和发布产物，官方 Release 仅保留现代 x64/ARM 产物。
