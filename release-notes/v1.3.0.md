# cloud-node-rust 1.3.0

> **重发说明（hotfix re-spin ×3）**：本 tag 已前移以包含以下生产修复——
>
> - **配置收敛为单一 `configs/api_node.yaml`**：`runtime.yaml`/`runtime.yml` 及其背后的 RKE2/集群运行时子系统（选举、peer 同步、内部集群 API、元数据/purge 扇出、共享卷门控）整体移除。`xdp:` 与 API 连接信息同文件共存；`xdp:` 段缺失或 `enabled` 缺省 = 启用，`enabled: false` 为唯一关闭方式，`CLOUD_NODE_XDP` 环境覆盖保留。
> - **启用 XDP 即强制双向**：`upstream.mode` 不再可选——启用态恒为 AF_XDP 出向，无 kernel-outbound 逃逸口；遗留 `upstream.mode: kernel` 键触发显式校验警告，AF_XDP 注册表缺失为硬错误而非静默回退。
> - **SNI 转发修复（重发版无法 SNI 的根因）**：出向切至 AF_XDP 后，SNI 透传回源走 AF_XDP 拨号路径，两处与内核 `connect()` 的不对称导致失败——① 只取 `lookup_host` 首个地址（内核逐一尝试全部解析结果），现遍历所有地址并聚合逐地址错误；② 冷邻居表项即时失败（内核 connect 隐式完成 ARP/ND），现先发 UDP 探针触发邻居解析、50ms×~900ms 轮询，仍无法解析则 fail-closed。
> - **安装器自动迁移**：`xdp:` 写入 `configs/api_node.yaml`；检测全部 4 个历史位置（`configs/runtime.y*ml`、`runtime.y*ml`）——`api_node.yaml` 无 `xdp:` 时迁入旧块，`xdp:` 之外内容丢弃，旧文件统一备份后删除；`--xdp-upstream` 拒绝（启用=双向），`--no-xdp` 写 `enabled: false`。
> - **零警告治理**：全部编译警告按根因清理——Linux-only 项以真实 `#[cfg(target_os="linux")]`/`#[cfg(any(test, linux))]` 门控替代 `cfg_attr(allow(dead_code))`，`RuntimeConfig` 收敛单字段后的 `..Default` 展开、macOS 死代码全部消除；Linux `cargo check`/`clippy --all-targets` 零警告。
> - **CI**：release 工作流改为仅 `v*` tag 触发，构建缓存切换 mbx 共享编译缓存（`actions/cache` 持有 store，tag 构建亦可回写）。
>
> 此前两次重发修复仍然包含：AF_XDP 会话表耗尽准入阶梯（L4 压力 70/85/95%、未验证预算 max(256,总量/8)、每源 64）、afxdp 空闲忙转事件驱动等待、空 `queues:` 冷启动 panic、64MiB kernel-bpf 地板、warming/120s 健康宽限。
>
> 验证：Linux `cargo check`/`clippy --all-targets` 零警告、`cargo test --lib` 859 通过；macOS `cargo check --all-targets` 零警告；安装器 5 场景迁移沙箱全部通过（迁移、authoritative-skip、无 xdp 旧文件、缺 api_node、`--no-xdp`）。

本版本是 XDP/AF_XDP 生产化里程碑（v1.2.7 以来 212 个提交、356 个文件、+144k/-12k 行）：交付完整的 eBPF 内核数据面 + AF_XDP 用户态反应堆 + EdgeCC 受控传输层 + 17 轮有界内存治理，内核 6.1 验证器下 native drv 挂载实测通过，真实三机拓扑验证完成。安装器收敛为单一双语流程、内置 GeoIP 源，并默认启用双向 XDP 数据面。

## 一、eBPF/XDP 内核数据面

### 转发与 NAT

- eBPF UDP direct forwarding：NAT + conntrack + per-CPU 计费。
- eBPF TCP direct-forward NAT + conntrack + billing 修正。
- tail-call NAT 子程序，按地址族拆分（IPv4/IPv6 独立 fast path）。
- per-forward SNAT（云端反欺骗），SNAT 探测基数每次尝试重随机化。
- QUIC long-header 按 DCID 映射 steering 到 owning AF_XDP 队列。
- eBPF per-IP 速率限制（压力自适应阈值）。

### 验证器与 ABI

- 通过内核 6.1 验证器：scratch checksum words、doff smin 收紧、SNI Err passthrough（另在 7.0 上验证干净）。
- ABI v12→v17 演进；ABI 不匹配时 attach 前清除 stale pinned maps。
- SNI blocklist 内核 fast path 曾引入后**移除**——域名决策保留在 L7（原则：内核不做域名判断）。

- EN-04 `src/xdp.rs` 拆分模块目录。
- EN-05 有界解析 + 显式分类 + 分片策略；队列级故障隔离 + 拥塞门。
- EN-06 受保护服务、redirect 解耦、NAT work-program 拆分。
- EN-07 聚合预算 + 准入门 + per-service 新流公平预算。
- EN-08 源地址公平性 + 有界 rate-map GC。
- EN-09 有界半开准入状态 + 流生命周期。
- EN-10 连接 owner 反馈 + 驻留流接管。
- EN-11 NAT 消歧、SNAT 端口生命周期、promotion 失败原子性、GC 预算、故障注入。

- EN-17 AF_XDP TCP 反应堆 hot-set 调度 + per-packet alloc/copy 消除 + 有界唤醒集 + 批量 cursor 扫描。
- EN-20~24 AF_XDP 出向链路：dial 通路 + 内核守卫、四个回源连接面接管、PMTU/ICMP 错误处理 + RFC4821 黑洞回退、ICMPv6 PTB 在线注入闭环、内核 6.1 验证器 native drv 实测。
- EN-25 最终验收：全量矩阵 + 消融 + 工件哈希。

### F 系列修复（F1~F8）

## 二、AF_XDP 用户态

- per-queue pinned 反应堆线程替代单 poll 任务；队列 reactor 内对 spawned proxy 任务 yield。
- AF_XDP L7 流上消费 PROXY 协议 + 对等审计。
- 压力自适应 accept worker + 空闲 relay 缓冲区收缩。
- 跨队列 UDP 路由投递修复（per-queue reactor 拆分后）。
- smoltcp 设备 Tx-only checksum 声明。

## 三、EdgeCC 传输层（T1~T9）

- T1 单调 µs transport clock + per-session snapshot 骨架。
- T2 模型/推断/包络基础层 + 参考控制器（NewRenoRef/CubicRef —— 非生产算法）。
- T3 smoltcp-edge 受控 fork + 外部传输控制器接线。
- T5~T9 算法层：EdgeCC 决策机 + 聚合/选路/调度/CoDel/AccECN + 用户态接线（EdgeCC 装配 + ECN 元数据链 + 调度器/自适应缓冲）。
- T7 AccECN（RFC 9768）wire + socket 层。
- sim 事件路径 O(1) 化 + qdelay 度量修正 + 三处事件/度量缺陷修复（同刻 RTO 自旋、retx pacing 逃逸、SACK RTT 采样时机）。

## 四、关键缺陷修复（真机复现闭环）

- **AF_XDP TCP relay 泄漏（128 会话冻结）**：`CloseWait` 未纳入读端关闭集合——对端 FIN 后 `poll_read` 永久挂起，任务持有的许可耗尽 fd 派生限额 `(nofile-512)×25%=128`。修复后真机 churn：`backendConnect 501/501`、`relayStart=501/relayDone=500`、零泄漏。
- **终态会话不回收**：proxy-started 与 pre-proxy 会话到达 `Closed`/`TimeWait` 立即置 `closing`，250ms 扫表回收，不再依赖 300s 空闲超时。
- **拨号 ~99ms 延迟**：每次拨号 fork 3 个 `ip` 子进程解析路由。新增有界路由缓存（TTL 5s、上限 4096、超时失效、无静默回退）——实测 501 次拨号仅 22 组解析，开销降 ~95.6%。
- **fd 限额放大器**：派生限额钳制到名义下限以下时输出一次性可观测告警。
- `sendfile_from` 误用 async `try_io`（tokio 版本语义修正）。
- 同 key 缓存锁死锁；hit-path 残余序列化与拷贝第二轮消除。
- block 响应误广告 keep-alive 修复。
- Elevated 压力下 L4 block 阈值伸缩 + AF_XDP PROXY 修复。
- dispatch map + tail-call 子程序 pin 住（forward 退出后存活）。
- 真实 checksum 验证、附加挂载流程补 `drop_stale_pinned_maps`。
- TCP smoke 瞬时错误重试。

## 五、内存治理（17 轮加固）

- 有界 WAF scoped-state 映射（固定容量槽位表 + 最早到期逐出）；scoped-network 检查每调用一次 ArcSwap load。
- 指标基数上限、防火墙持久化队列上限。
- 准入限额物化为代次标记表 + TTL 感知（压力/fd 信号物化）。
- 分片准入计数器 → padding 类行 + 共享账本推导（拒绝计数器消除伪共享——泛洪时恰是伪共享最痛处）。
- 账本一致性、有界映射、PSI 压力、reclaim 硬化；reclaim 机制 panic 包容 + 幂等 monitor + 孤儿账本退款对账测试。
- 热路径 poison-tolerant 锁；L1 按真实堆成本计重；UDP DNS single-flight 取消安全。
- High/Critical 压力下 in-flight 请求预防性 shed；per-connection ticket pool。
- WAF/pending 逐出批量随容量伸缩 + RSS bench。

## 六、安装器

- **单一流程**：自动检测现有部署执行迁移/升级，无 `api_node.yaml` 进入全新安装；删除新装/升级/迁移模式区分。
- **全量双语输出**：所有用户可见消息中英文同行；删除语言选择交互。
- **GeoIP 必装**：`geoip/` 目录入库（City/ASN/Country，~86MB）+ `SHA256SUMS.txt` 强制验签；更新节奏由维护者控制；`--no-geoip` 显式警告但继续安装。
- 下载进度动画（TTY 感知：盲文 spinner + 进度条 + 百分比/字节/速率；非 TTY 回退普通日志；`NO_PROGRESS=1` 关闭）。
- **网卡 XDP 能力报告**：内核底线、逐网卡驱动判定（native drv / conditional / generic-skb）、AF_XDP 零拷贝子集标注、已挂载检测、默认路由网卡标记、噪声接口过滤。
- **XDP 默认启用（双向）**：交互安装询问 XDP 数据面开关、默认选项为启用；非交互/`--yes` 同样默认启用。启用即生成双向配置：`xdp.enabled: true` + `attachMode: auto` + `interfaces`（探测默认路由网卡，失败则留空由运行时自动推导）+ `upstream.mode: afxdp`——入向代理与出向回源均走 XDP/AF_XDP，无静默内核回退。显式退出：`--no-xdp` / `ENABLE_XDP=no` 写入 `xdp.enabled: false`；`--xdp-iface NAME` 可指定绑定网卡。升级场景：既有配置缺少 `xdp:` 段时按同一默认追加（先备份 `.pre-xdp`），已有 `xdp:` 段的配置保持权威不改动。
- 修复：restore 交互输出污染备份路径（改走 stderr）；`mapfile` 换 bash 3.2 可移植实现。
- 兼容层：`--fresh`/`--geoip`/`--install`/`--upgrade`/`--lang`/`--no-timezone` 等旧参数静默接受；`START_MODE`/`MODE` 环境变量仍映射。
- 默认自动启动/重启 + 状态校验（`--no-start` 退出）。

## 八、性能与防御验证

- **OrbStack veth 基线**：1.01M pps CT-hit、SNAT 成本 8%。
- **真实三机拓扑**（客户端 → ens17 virtio native drv → 源站，双向 ~4ms WAN）：AF_XDP HTTP + 内核上游 **983 rps**（内核路径 476 rps）、0 丢包；AF_XDP TCP FIN churn 599.7 cps；HTTPS 终结 422 rps keepalive；kernel TCP 528.5 cps。
- **修复后窗口同步 churn**：FIN/RST 各 250 周期、0 丢包、`drop/mapMiss/xskDrops` 全零、会话有界。
- **fail-closed 实测**：dial guard 安装失败时 registry 不发布，全部拨号显式报 "no live AF_XDP dial registry"，零静默内核回退。
- 四协议压测矩阵（h1/h1s/h2/h3）+ WAF/CC/L4 防御测试矩阵；true sendfile 缓存命中 + QUIC transport tuning + 动态 passthrough group。
- NotKeyed direct limiter + `BENCH_CC_TOTAL_QPS` 全局配额；kernel-offload filter 开关 + per-phase 内核命中记账。
- raw-smoke 转发计数器 + veth/SKB SNAT 基线。
