# cloud-node-rust 1.3.0

本版本交付生产化的 XDP/AF_XDP 数据面与有界内存治理体系：eBPF 程序在内核 6.1 验证器下以 native drv 模式挂载实测通过，AF_XDP 覆盖入向代理与出向回源双腿，全链路状态、队列、任务、缓冲区均有显式上限与可观测回收。安装器收敛为单一双语流程并内置 GeoIP 源。

## XDP / AF_XDP 数据面

- **入向代理**：XDP → AF_XDP → 既有协议处理链（HTTP/1.1、HTTPS、H2、H3、TCP、UDP、SNI 透传、QUIC 终结、`@quic` 透传、IPv4/IPv6），TLS/WAF/路由/计费/超时/背压语义不变。
- **出向回源**：四个回源连接面可由 `xdp.upstream.mode=afxdp` 接管（EN-20~EN-24）；PMTU/ICMP 错误处理 + RFC4821 黑洞回退；ICMPv6 PTB 在线注入验证闭环。
- **内核侧能力**：无状态 TCP cookie challenge + splice（EN-14）、自适应 QUIC Retry（EN-15）、per-CPU 计数器与终态记账（EN-03）、分层预算与准入门（EN-07/EN-08/EN-09）、NAT 消歧与 SNAT 端口生命周期（EN-11）、半开连接有界准入、受保护服务与重定向解耦（EN-06）。
- **用户态反应堆**：队列级故障隔离与拥塞门（EN-05）、worker 租约与队列正确性（EN-12）、hot-set 调度 + 有界唤醒集（EN-17）、连接 owner 反馈与驻留流接管（EN-10）、迟滞与状态表（EN-16）。
- **生命周期安全**：prepare-before-commit 挂载、跨代 dataplane 租约移交（F1）、owner 感知 reload、链接拆卸 EBUSY 重试、按预算自动伸缩状态表。
- **EdgeCC 传输层**：单调 µs transport clock、smoltcp-edge 受控 fork、AccECN（RFC 9768）wire/socket 层、EdgeCC 决策机 + 聚合/选路/调度/CoDel/自适应缓冲（T1~T9）。

## 关键修复（真机复现闭环）

- **AF_XDP TCP relay 泄漏（128 会话冻结）**：`CloseWait` 未纳入读端关闭集合导致对端 FIN 后 `poll_read` 永久挂起，任务持有的许可耗尽 fd 派生限额 `(nofile-512)×25%=128`。修复后真机 churn：`backendConnect 501/501 成功`、`relayStart=501 / relayDone=500`、零泄漏。
- **终态会话不回收**：proxy-started 会话到达 `Closed`/`TimeWait` 后立即置 `closing`，250ms 扫表回收，不再依赖 300s 空闲超时。
- **拨号 ~99ms 延迟**：每次拨号 fork 3 个 `ip` 子进程解析路由。新增有界路由缓存（TTL 5s、上限 4096、超时失效、无静默回退）——实测 501 次拨号仅 22 组解析，子进程开销降 ~95.6%。
- **fd 限额放大器**：派生限额被钳制到名义下限以下时输出一次性可观测告警。

## 内存治理（17 轮加固）

- 有界 WAF scoped-state 映射（最早到期逐出）、指标基数上限、防火墙持久化队列上限、metrics/firewall 泛洪面收敛。
- 准入限额物化为代次标记表 + TTL 感知；拒绝计数器 padding 消除伪共享；账本一致性、PSI 压力、reclaim 硬化。
- reclaim 机制 panic 包容、热路径 poison-tolerant 锁、孤儿账本退款对账、幂等 monitor、L1 按真实堆成本计重。
- High/Critical 压力下 in-flight 请求预防性 shed；per-connection ticket pool；UDP DNS single-flight 取消安全。

## 安装器

- 收敛为**单一流程**：自动检测现有部署执行迁移/升级，无 `api_node.yaml` 时进入全新安装；删除新装/升级/迁移等模式区分。
- **全量双语输出**：所有用户可见消息中英文同行显示。
- **GeoIP 必装**：数据库镜像入仓库 `geoip/`（含 `SHA256SUMS.txt` 验签），由维护者控制更新节奏；`--no-geoip` 显式警告但继续安装。
- 下载进度动画（TTY 感知：盲文 spinner + 进度条 + 速率，非 TTY 回退普通日志）。
- 安装收尾输出**网卡 XDP 能力报告**：内核版本底线、逐网卡驱动判定（native drv / conditional / generic-skb）、AF_XDP 零拷贝子集、当前挂载状态、默认路由网卡标记、噪声接口过滤。

## 发布工程

- CI Check/Test 安装 pinned eBPF nightly + `build-ebpf`；bpf-linker 链接工具链自带 libLLVM（`rustc-dev` + sysroot 符号链接），摆脱系统 LLVM 版本依赖。
- eBPF 对象随源码固定 nightly 构建、SHA256 校验后嵌入；release 产物与 `data/cloud-node-xdp-ebpf.o` 字节一致可证。
- **零警告**：`cargo check --all-targets` 与 `cargo clippy --all-targets -D clippy::correctness -D clippy::suspicious` 在 Linux 下无任何 rustc/clippy 警告（含 eBPF 与 vendored 依赖）。
- fat-LTO 五个发布 target：x86-64 v2(SSE4.2) / v3(AVX2) / v4(AVX-512)、arm64 generic、arm64 Neoverse-N1。

## 真实拓扑验证

- 三机实测（客户端 → ens17 virtio native drv → 源站，双向 ~4ms WAN）：AF_XDP HTTP + 内核上游 **983 rps**（内核路径 476 rps）、0 丢包；AF_XDP TCP FIN churn 599.7 cps；HTTPS 终结 422 rps keepalive。
- 修复后窗口同步 churn：FIN/RST 各 250 周期、0 丢包、`drop/mapMiss/xskDrops` 全零、会话有界。
- fail-closed 契约实测：dial guard 安装失败时 registry 不发布，全部拨号显式报错，零静默内核回退。

## 行为与兼容性

- 内核要求：eBPF 对象 ABI 面保守（helper 均为 4.x/5.x 时代 + RingBuf ≥5.8），Debian 12 默认 6.1 LTS 与 backports 6.12 LTS 均无需适配。
- 所有回退路径显式可观测：不支持 native XDP 的网卡建议 `xdp.attachMode=auto|skb`；任何失败均记录原因，无静默降级。
- `xdp.enabled=false` 可完整退出并拆卸挂载。
- 旧安装器参数（`--fresh`/`--geoip`/`--install`/`--upgrade`/`--lang` 等）保留兼容 no-op。
- 二进制名 `edge-node` 不变；`h3_probe` 诊断工具更名为 `h3-probe`（kebab-case）。
