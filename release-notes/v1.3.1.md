# cloud-node-rust 1.3.1

> **重发说明**：本 tag 再次前移——在既有 AF_XDP 修复之上追加完整的数据面稳定性修复集与多核扩展架构，全部经生产机（virtio_net，Debian 13 + kernel 7.1.8）实测验证。
>
> - **空 ACK 洪泛修复（CPU/断流主因）**：smoltcp `dispatch` 在 pacing 推迟数据时反复 emit 零载荷包（实测 ~33k pps、empty:data ≈ 1900:1），占满 TX 通道并挤出真实段制造"伪丢包"。现空包抑制 + `poll_at` 节拍保证按时重试，empty:data 降至 ~1:4。
> - **RTT 污染修复**：emit 打戳早于上线时刻，ACK 采样把用户态队列滞留算入路径 RTT（实测 2.47s 假值 vs 真实 ~80ms），EdgeCC guardrail 随之持续收紧致速度归零波动。改为 emit-gate 背压（egress ≥512 跳过 poll_egress）+ dwell 只观测不丢帧（`stale_dwells` 计数）。
> - **EdgeCC policer 收敛**：`lt_bw` 判决从抖动的 bw_est EWMA 改为 bw_slope（防压缩交付率），RTO 声明的丢包也计入丢包轮次；pin 值锚定 `peak_slope / (1-loss)` 估算 policer 真实速率——sim 验证钉到 ~1.6MB/s ≈ policer 1.25M 而非停滞吞吐 ~5KB/s。
> - **僵尸会话上界**：smoltcp 无 RTO 放弃上限，死对端重传刷新活跃时间戳导致 idle reap 永远抓不到（生产实测 ~172 条死流残留 ~60% 单核 CPU）。现 **10 次连续无进展 RTO → 连接关闭**，CPU 随会话数衰减得到验证。
> - **Worker steering 多核扩展**：会话归属改为 `fnv1a(flow) % workers` 无状态分发（不再依赖 RSS 运气），跨 worker 一跳 bounded channel 保序转发；`steered_frames`/`steer_sheds` 入状态。配合队列数自动探测 + `ordinal % cpus` 绑核，任意核心数均可水平扩展。
> - **XSK 双层门控**：`auto` = zero-copy→driver-copy 探测（不支持 zc 落 copy 如实上报 `xsk_mode`）；驱动管理 XSK 地板门控（virtio 6.11/ena 5.16/gve 6.2/主流 NIC 5.4）拒绝 generic 路径；`xskMode: copy` 保留为显式测试通道。
> - **安装器**：NIC 调查分档显示 zero-copy capable / driver copy / unsupported；启用 XDP 后可选 **proxy**（全量数据面）或 **protect**（仅防御、流量走内核栈）；`--upgrade-kernel` 内核优先、系统兜底的双路径升级，完整计划 + **双重确认**（yes/no + 输入 UPGRADE）后自动执行并 10s 倒计时重启。
> - **virtio zero-copy 澄清**：上游 6.13 起声明 `NETDEV_XDP_ACT_XSK_ZEROCOPY`，但要求 hypervisor 协商 `VIRTIO_F_ACCESS_PLATFORM`（本机 bit33=0 → EINVAL by design）。UMEM `frame_headroom=32` 已预置满足 virtio hdr 要求，可用环境自动落地 zc。
>
> 验证：Linux `cargo test --lib --bins` 845 通过（1 个已知并行共享态 cache flake 隔离后通过）；生产机 anytls/SNI 实测——重发峰值从 285-324 次/段降至 3-7 次、出向 SACK 空洞归零、速度从归零波动恢复稳定。

## 部署注意

- **内核要求**：AF_XDP 需要内核 ≥5.4 + 驱动管理 XSK（virtio ≥6.11）。低于底线 `xdp.enabled` 会被拒绝并保持内核路径。
- **zero-copy**：驱动声明 ZEROCOPY 时自动落地（virtio ≥6.13 + hypervisor `ACCESS_PLATFORM`；物理 NIC i40e/mlx5 等原生支持）；否则落 driver copy。
- **安装器升级**：`--upgrade-kernel` 在门控不满足时先尝试发行版内核包，不足时提供系统发行版升级——双重确认后自动执行并重启。
