# cloud-node-rust 1.1.8 未发布

本文件记录下一版本候选变更，当前不发布版本、不打 tag、不创建 GitHub Release。正式发版前需要重新确认版本号、兼容性说明和发布制品矩阵。

## XDP/AF_XDP 数据面

- 新增 Linux-only、默认关闭的 XDP/AF_XDP protect/proxy 数据面。
- 新增 `configs/runtime.yaml` 的 `xdp` 配置段，支持 `attachMode`、`fallback`、接口、队列、模式、本机 IP 过滤、frame size、proxy 协议和端口配置。
- 新增 Aya eBPF XDP 程序和共享 map 类型，支持 IPv4/IPv6、TCP/UDP、exact allow/block、LPM、range、proxy port、local IP、XSK map 和 counters。
- 新增 `cargo xtask build-ebpf`，将 eBPF 对象构建到 `data/cloud-node-xdp-ebpf.o`。
- 新增 `cloud-node xdp status|doctor|attach|detach|dump-maps|reload`，并提供 raw/proxy/reload smoke 诊断命令。

## 协议旁路

- AF_XDP proxy 支持 HTTP、HTTPS、L4 TCP、UDP、SNI 透传、QUIC 透传和 HTTP/3。
- AF_XDP TCP stream 接入现有 HTTP/TCP/SNI 路由，保留 PROXY protocol、L4 防护和 relay 行为。
- AF_XDP UDP datagram 接入现有 UDP session、QUIC demux、H3 manager、CID route 和 pending-route 防护。
- proxy 模式只 redirect 命中端口和就绪队列；未命中、XSK 未就绪或降级时继续走原 socket listener。

## 防护、状态和回退

- `kernelFirewallMode` 支持 `xdp`；`auto` 在本机 XDP 配置启用且 attach 成功时优先使用 XDP filter，否则保持原 nftables/iptables/noop 回退。
- `KernelFilter` 扩展 block network、range、snapshot sync 和 status 能力；XDP 后端同步 IP、CIDR、range 和 allow 覆盖。
- 节点状态上报新增 `xdp` JSON，包含 attach、fallback、proxy、XSK queue、map 和 counter 状态。
- reload 时对未变化的 AF_XDP bridge 做保留，避免重复绑定队列造成中断。
- 新增 L4 连接注册和 SYN pressure 可观测性，辅助 XDP/AF_XDP proxy 在压力态下保持可控关闭和排障。

## 测试和验证

- 新增 `scripts/xdp-netns-smoke.sh`，覆盖 veth/netns attach、allow/block、raw AF_XDP redirect、HTTP/HTTPS/TCP/UDP/SNI/QUIC/H3 proxy、reload 和 detach。
- 新增 AF_XDP 用户态单测，覆盖 frame parser、VLAN/QinQ、IPv6 extension、TCP reactor、half-close、route cache、backpressure、TX failure 和 datagram fallback。
- 已验证：

```bash
cargo check --all-targets --jobs 1
cargo test --lib af_xdp --jobs 1
cargo xtask build-ebpf
bash scripts/xdp-netns-smoke.sh
```

## 兼容性

- 默认不启用 XDP，现有部署不需要修改配置。
- 非 Linux 平台保留原行为；XDP 命令会报告不可用。
- 需要标准 MTU、合适网卡队列和必要 capability；jumbo/multi-buffer 场景仍建议先用 `doctor` 检查。
- XDP/AF_XDP 失败默认 fail-open 到原 socket 数据面；需要 fail-closed 时显式配置 `fallback: fail-start`。
