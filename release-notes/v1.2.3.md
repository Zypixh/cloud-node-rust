# cloud-node-rust 1.2.3

## 概述

1.2.3 是 1.2.2 的补丁版本，消除全部 lib 编译 warning 并清理死代码，无功能行为变更。

## 代码清理

- 移除 `rewrite.rs` 中未使用的 import。
- 将 `mace_backend` 限定为 `#[cfg(test)]`：生产存储走 `storage.rs`，消除 27 个 dead code warning。
- 删除 `parse_remote_ip` 遗留包装（已由 `client_ip` 模块替代）。
- 删除 `AdaptiveBloomFilter::remove` 空实现。
- 删除已被 `apply_rule_diff` 取代的 XDP 规则 sync 辅助函数（`sync_exact_ip_map`、`sync_network_map`、`sync_range_lpm_maps`）。
- 修正 AF_XDP session 初始化，去掉不必要的 `mut`。
- `tcp_packet_is_initial_syn` 限定为测试专用（`#[cfg(test)]`）。

未使用任何 `#[allow(...)]` 或编译器 warning 屏蔽选项。

## 升级说明

- 从 1.2.2 升级：**可直接替换二进制**，无配置或数据格式变更。
- 从 1.2.1 升级：请先阅读 [1.2.2 发布说明](v1.2.2.md)。
