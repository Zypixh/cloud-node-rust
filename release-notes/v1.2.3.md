# cloud-node-rust 1.2.3

## 概述

1.2.3 修复低内存节点在大规模完整配置同步和批量 configChanged 热更新期间的瞬时内存放大，降低旧配置代、运行时映射、负载均衡器与健康检查任务叠加导致的 OOM 风险。

## 低内存配置同步

- 完整节点配置使用流式解析压缩 JSON，避免完整解压缓冲与已解析配置同时常驻。
- 每个 ServerConfig 只创建一个 Arc，所有域名索引共享该实例，不再按域名复制完整站点配置。
- 根据 memory governor 的可用内存分块建立站点运行时映射；压力过高时延后单站点配置任务。
- High/Critical 压力下先释放旧服务器映射、LB 和编译计划，再构建新配置代，并调用 malloc_trim 归还堆页。
- 增量热更新不再克隆完整 NodeConfig 或重新编译全部计划，仅替换变更的站点。
- 健康检查使用 Weak 引用；排队探测不再阻止旧配置代释放。

## WAF / 访客 IP

- 新增 WAF 规则变量 `geoAsn` / `asn`、`geoAsnNumber` / `asnNumber`（需 GeoLite2-ASN 数据库）。
- 新增 `src/client_ip.rs`，统一 HTTP 会话的 `resolve_client_ip` / `raw_remote_addr` / `peer_socket_ip` 逻辑。
- 防火墙、访问日志、缓存 key、RPC 等模块统一使用 `client_ip` 解析结果。
- 公网直连 peer 不再信任 `X-Forwarded-For` 等 header（防伪造）。

## 内存治理与 OOM 防护

- 扩展 `memory_governor`：读取 cgroup memory.max/high/swap、RSS/PSS 采样，四级压力（Normal / Elevated / High / Critical）。
- 新增 `memory_reclaim` 模块：按压力级别回收 L1 缓存、Bloom 层、负缓存、Geo/UA 缓存、WAF regex 缓存等。
- 常驻内存账本（`ResidentCategory`）：cache metadata、access log、surrogate index、Bloom、negative cache 带上限准入。
- Surrogate-key 反向索引与双代 Bloom filter 带上界；高压下可 shrink / reset。
- 新增 `bounded_regex_cache`，限制 WAF 正则编译缓存规模。

## 节点日志

- API 不可用期间对相同 node-log key 限流（5 分钟 / 连通性失败 10 分钟）。
- 上传失败指数退避（5s → 最大 5 分钟），避免控制面 DB 被重复失败日志淹没。

## 存储

- 恢复 `upsert_cache_meta_absolute_async` / `delete_cache_meta_async`：热路径立即更新内存索引，Mace 磁盘写入 offload 到 `mace-cache-writer` 专用线程。
- 同步 API 保留用于启动加载、测试与 `update_cache_meta`。
- 修复合并后编译错误（API 不匹配、DashSet 类型、Bloom 回收方法、const fn 等）。

## 代码清理

- 移除 `rewrite.rs` 中未使用的 import。
- 将 `mace_backend` 限定为 `#[cfg(test)]`：生产存储走 `storage.rs`。
- 删除 `parse_remote_ip` 遗留包装（已由 `client_ip` 模块替代）。
- 删除 `AdaptiveBloomFilter::remove` 空实现。
- 删除已被 `apply_rule_diff` 取代的 XDP 规则 sync 辅助函数。
- 修正 AF_XDP session 初始化，去掉不必要的 `mut`。
- `tcp_packet_is_initial_syn` 限定为测试专用（`#[cfg(test)]`）。

未使用任何 `#[allow(...)]` 或编译器 warning 屏蔽选项。

## 安装脚本

- 覆盖安装前先 stop + unregister 旧版 cloud-node systemd 单元，避免端口/数据目录被旧进程占用。

## CI / 构建

- Release workflow 扩展 path 过滤，版本 bump / release notes / 源码变更可触发构建。
- 构建前后 `cargo clean` 降低 matrix 磁盘占用。
- `xtask` 将 `migrate-metrics` 设为可选 feature，默认 `build-ebpf` 不再依赖 RocksDB 迁移 crate。

## 升级说明

- 从 1.2.2 升级：**无数据格式变更**，`data/metrics.mace` 目录保持不变。
- 对内存小于 2 GiB 且站点数、域名别名或 configChanged 频率较高的节点，建议优先升级；High/Critical 压力下的完整配置切换会短暂使新请求的站点查找失败，直到新代映射发布。
- WAF ASN 规则需额外下载 GeoLite2-ASN mmdb（与 GeoIP 相同来源）。
- 若使用自定义 IP header 解析，请确认 `HTTPRemoteAddrConfig` 行为符合预期（公网 peer 不再信任 XFF）。
