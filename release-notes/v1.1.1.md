# cloud-node-rust 1.1.1

本文件记录 `1.1.1` 的发布说明。

## 概述

1.1.1 是一次数据面性能和可靠性更新，重点降低高 QPS、攻击流量、大缓存对象和大量 TLS/UDP 会话下的 CPU、内存、锁竞争和 I/O 放大。本版本不改变控制面协议和对外配置语义，主要优化运行时热路径。

## 缓存命中路径

- L2 磁盘缓存命中优先读取内存元数据索引，减少请求热路径 RocksDB I/O。
- 小对象 L2 命中继续返回内存 handler，保持 Fast L1 晋升能力，避免热小文件退化为每次磁盘读取。
- 大对象 L2 命中改为文件分块读取，避免整文件一次性读入内存。
- 压缩缓存对象支持流式 zstd 解压；小压缩对象仍可解压到内存后走 Fast L1 晋升路径。
- 修正多 cache root 路径选择，使额外缓存根目录参与对象查找。
- 缓存访问时间和次数先写入内存，后台批量 flush 到 RocksDB，降低 cache HIT 热路径 I/O。
- 启动缓存访问 flush、缓存 janitor 和缓存 purger 后台任务，确保元数据和磁盘对象持续维护。

## WAF 和响应体处理

- CC 和计数型规则从时间戳列表改为固定窗口滚动桶，降低单 key 高并发或攻击流量下的线性扫描成本。
- 计数器 key 包含统计周期，避免同一业务 key 在不同周期规则间互相覆盖。
- 响应体 HTML/CSS/JS 优化增加大小边界，超过阈值直接透传，避免大响应全量聚合和阻塞处理。
- 出站 WAF 响应体检测在评估前保留待检查前缀，避免未检查内容先发送给客户端，并确保每个响应体只执行一次完整评估。

## 日志和指标

- 访问日志构造按字段开关惰性生成 headers、cookies、attrs、tags 和 request body，减少请求完成阶段不必要分配。
- 请求体日志继续遵守 2 MiB 上限，未启用该字段时不复制请求体。
- 访问日志上传按 protobuf 编码大小拆分 chunk，并在 `ResourceExhausted` 时先剥离大字段再重试。
- 修复访问日志批量上传中间 chunk 失败时丢弃后续未发送 chunk 的问题；失败后会按顺序重新入队当前失败日志和所有剩余日志，并继续遵守 retry buffer 上限。
- HTTP 指标记录减少不必要的 IP 字符串复制，Top IP 支持直接记录 `IpAddr`。

## UDP、QUIC 和 TCP/TLS 热路径

- UDP 服务按端口建立配置索引，新 session 不再扫描全量 server。
- UDP session 和 QUIC demux route 的活动时间改为原子时间戳更新，减少每包锁竞争。
- QUIC demux 保持 HTTP/3、`@quic` 和普通 UDP fallback 语义不变，同时降低高包量下的活动更新时间成本。
- HTTP/3 generic fallback 仅允许已绑定且启用 HTTP/3 的域名进入 H3 路由，非绑定域名不再创建 QUIC/H3 路由状态。
- HTTPS 和 TCP-TLS 下游握手增加配置派生的总超时，避免半 TLS 握手连接长期占用 fd、socket 和内存。
- HTTP/1 下游连接在读取首个请求头前即设置读超时，HTTP/2 preface/handshake 也受配置派生超时保护。
- 非绑定域名响应后禁用 HTTP/1 keep-alive，使直连 IP、未绑定 Host 和域名不匹配请求尽快释放连接。
- TCP 上游 TLS 连接器复用，减少每条 TLS 回源连接重复初始化成本。
- 客户端证书 PEM 解析结果加入 LRU 缓存，容量根据当前配置中唯一证书数量动态调整，不使用固定 CDN 容量。

## 证书和 OCSP

- TLS 证书 SNI 选择快照改为 `ArcSwap`，握手热路径读取不再持有全局 `RwLock`。
- OCSP 数据改为 `ArcSwap<Vec<u8>>`，证书握手设置 OCSP staple 时不再获取读锁。
- 证书同步仍复用未变化证书的解析结果，避免配置刷新时重复解析相同证书链和私钥。
