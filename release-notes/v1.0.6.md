# cloud-node-rust 1.0.6

本文件记录 `1.0.6` 的发布说明。

## 概述

1.0.6 重点补齐控制面 PB 协议兼容和节点运行时行为，修复真实 API 通信中的上线状态、`nodeStream` 长连接、配置解析应用和部分 Go 时代功能差异。同时继续收敛热路径阻塞、锁竞争和不必要日志输出。

本日志已剔除由开发过程中临时实现、回滚或中间错误引发的修复记录，只保留对最终功能、兼容性、性能和运维有意义的变化。

## 控制面协议兼容

- 修复节点上线状态上报：配置应用成功后立即调用 `updateNodeStatus`，确保控制端能看到节点在线和健康状态。
- 保持 Go 兼容的节点 token 载荷，认证 token 中的 `type` 固定为 `node`。
- 兼容控制面 `nodeId` / `token` metadata，避免不同 gRPC 实现对 metadata 大小写处理差异造成认证失败。
- 增加真实 API 集成测试，覆盖配置拉取、Brotli 解压、PB JSON 解析、配置应用、状态上报和 stream 保持。
- 增加 30-60 秒真实 API 长连接测试窗口，避免只验证瞬时 RPC 成功。

## nodeStream 长连接

- 实现底层 HTTP/2 gRPC frame 版 `nodeStream`，用于明文 HTTP endpoint。
- 请求流打开后立即发送 `ping` 并进入保持状态，不再把“服务端响应头已返回”作为建流成功前置条件，行为更接近 Go 客户端。
- 收到控制端消息后复用统一 `handle_message()` 分发执行动作，并按 `requestId` 回复结果。
- 已支持消息：
  - `connectedAPINode`
  - `newNodeTask` / `NewNodeTask` / `configChanged`
  - `writeCache`
  - `readCache`
  - `statCache`
  - `cleanCache`
  - `getStat`
  - `changeAPINode`
  - `checkLocalFirewall`
- 未识别消息会回复 `unhandled`，不会静默丢弃。

## 功能补齐

- 补齐域名不匹配处理，支持控制面兼容字段和节点 IP 页面配置。
- 补齐 Basic Auth、Referer 防盗链、User-Agent 策略解析和请求侧执行。
- 补齐本地防火墙检查代码页，当前只做能力检测；暂不启用完整 DDoS/nftables 规则托管。
- 增加暂不支持功能的代码占位页，明确标注暂不考虑自动升级、静态文件服务、请求脚本和 IP 库更新器等能力，避免误判为已实现。
- 增加配置兼容测试，验证控制端下发的兼容字段能正常解析并应用到热路径快照。

## 性能和稳定性

- 修复 `nodeStream` 建立阶段可能永久等待响应头的问题，避免后台 stream 任务卡死。
- 继续减少配置热路径克隆和锁获取。
- 优化访问日志和节点日志输出，保留关键配置获取、同步和错误信息，减少高并发场景下的杂乱 info 日志。
- 保持日志投递非阻塞，避免控制面异常反压请求热路径。
